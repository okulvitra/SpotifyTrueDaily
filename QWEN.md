# SpotifyTrueDaily Project Context for Qwen Code

## Project Overview

SpotifyTrueDaily is a Python application that automatically creates and updates a daily personalized Spotify playlist named "Journalière". It combines various content sources:

1.  **Podcasts:** The latest unlistened episodes from saved shows, filtering out audiobooks.
2.  **Music:**
    *   Recently played tracks.
    *   Top tracks (short-term).
    *   Random tracks from the user's library.
    *   (Optional) New music recommendations using the SoundStat API, seeded by recent/top tracks.
3.  **Interleaving:** The collected content is intelligently interleaved (e.g., 1 podcast episode followed by 3 songs) to create a varied listening experience.

The application is designed for daily use, either manually or automated via Windows Task Scheduler. It features a graphical user interface (GUI) built with `customtkinter` for easy configuration and execution.

## Core Technologies

*   **Language:** Python 3.x
*   **GUI Framework:** `customtkinter` (Tkinter-based)
*   **Spotify Interaction:** `spotipy` library
*   **API Calls (SoundStat):** `requests` library
*   **Packaging (Optional):** `PyInstaller` (for creating `.exe`)
*   **Dependencies:** Listed in `requirements.txt`.

## Project Structure

*   `app_gui.py`: The main script for the CustomTkinter GUI application. It handles user input for API keys (Settings tab) and content parameters (Application tab), triggers the playlist update in a background thread, and displays logs.
*   `playlist_manager.py`: The core logic script. It manages Spotify authentication (`spotipy`), fetches content (recent, top, podcasts, library, SoundStat), deduplicates and interleaves the content, and finally updates the "Journalière" playlist on Spotify. It also contains basic scheduling logic (though GUI execution is primary).
*   `config_template.py`: A template file that users must copy to `config.py` and fill in with their Spotify API credentials, SoundStat API key (optional), and default content parameters.
*   `config.py` *(Not versioned)*: The local configuration file generated by the GUI or manually created. Contains sensitive API keys and user preferences. This file is loaded by `playlist_manager.py`.
*   `requirements.txt`: Lists the Python packages required to run the application.
*   `.spotipyoauthcache` *(Not versioned)*: Cache file created by `spotipy` to store and reuse Spotify OAuth tokens after the initial manual authentication.
*   `run_playlist_update.bat`: A sample batch script for running the Python script version from the command line or Task Scheduler.
*   `SpotifyTrueDaily.exe` *(Not versioned, in releases)*: The standalone executable built with PyInstaller.
*   `SpotifyTrueDaily.spec`: The PyInstaller spec file used for building the executable.

## Key Features and Logic

*   **Spotify Authentication:** Uses `spotipy`'s `SpotifyOAuth` with a local cache file (`.spotipyoauthcache`) for seamless subsequent logins after the initial browser-based authorization.
*   **Playlist Management:** Checks for an existing "Journalière" playlist; if found, it uses it. If not, it creates a new private playlist.
*   **Podcast Handling:** Fetches saved shows, retrieves the latest episode for each, filters out episodes marked as fully played or identified as audiobook chapters, and selects up to the configured maximum number of unlistened episodes.
*   **Music Sources:**
    *   Queries Spotify for recently played and top tracks based on configured limits.
    *   Selects random tracks from the user's saved tracks, ensuring they are not already included from recent/top lists.
*   **SoundStat Integration (Optional):** If a SoundStat API key is provided and the relevant counts are > 0:
    *   Seeds are selected from recent and top tracks.
    *   Makes API calls to SoundStat for recommendations based on these seeds.
    *   Filters SoundStat recommendations to remove duplicates and items already present from other sources.
    *   Selects up to the configured maximum number of unique new recommendations.
*   **Content Interleaving:** Combines podcast URIs and music URIs (recent, top, library, SoundStat) into a single list, ensuring uniqueness. It then creates a new list by interleaving them (1 podcast, 3 songs, repeat) to produce the final playlist order.
*   **Playlist Update:** Clears the existing playlist content and adds the newly generated interleaved list of track/episode URIs.
*   **GUI Functionality:**
    *   **Settings Tab:** Allows secure input of Spotify and SoundStat API keys and default content parameters. Saves these to `config.py`.
    *   **Application Tab:** Allows dynamic adjustment of content parameters for the *current run* without altering defaults. Displays logs from the playlist update process. Triggers the update via a button click, running `playlist_manager.py`'s logic in a separate thread.

## Building and Running

### For Developers (Python Scripts)

1.  **Clone Repository:**
    ```bash
    git clone https://github.com/okulvitra/SpotifyTrueDaily.git
    cd SpotifyTrueDaily
    ```
2.  **Set Up Virtual Environment (Recommended):**
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # On Linux/macOS
    # .venv\Scripts\Activate.ps1 # On Windows (PowerShell)
    ```
3.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
4.  **Configure API Keys:**
    *   Copy `config_template.py` to `config.py`.
    *   Edit `config.py` and enter your Spotify `Client ID`, `Client Secret`, `Redirect URI`, and optionally your SoundStat `API Key`. Set your default content parameters.
5.  **Run the Application:**
    *   Launch the GUI:
        ```bash
        python app_gui.py
        ```
    *   Use the "Settings" tab to save your configuration if not done manually.
    *   Adjust parameters in the "Application" tab if needed for this run.
    *   Click "Start Playlist Update". If it's the first run or the cache is invalid, follow the browser authentication flow and paste the redirect URL into the console that opens.

### For Users (Pre-built Executable - Windows)

1.  **Download:** Get `SpotifyTrueDaily.exe` and `config_template.py` from the latest release.
2.  **Setup:** Place both files in the same directory.
3.  **Configure:** Run `SpotifyTrueDaily.exe`, use the "Settings" tab to enter your API keys and save the configuration (this creates `config.py`).
4.  **Authenticate (First Run):** Click "Start Playlist Update" in the "Application" tab, follow the browser prompt, and paste the redirect URL into the console.
5.  **Use:** Run `SpotifyTrueDaily.exe`, adjust parameters in the "Application" tab, and click "Start Playlist Update".

## Development Conventions

*   **Configuration:** Centralized in `config.py`, loaded by `playlist_manager.py`. GUI dynamically updates `config.py`.
*   **Error Handling:** Specific exceptions (`ConfigError`) and general `try...except` blocks are used to catch errors during configuration loading, API calls, and GUI operations. Errors are displayed in the GUI or printed to the console.
*   **Logging/Output:** Standard `print` statements are used extensively for logging within `playlist_manager.py` and `app_gui.py`. The GUI redirects `stdout`/`stderr` to a text area.
*   **Threading:** The playlist update process is run in a separate thread in the GUI to prevent the interface from freezing.
*   **API Limits:** Basic `time.sleep` calls are used between some Spotify API requests to be respectful of rate limits. SoundStat API calls also use specific limits per request.
*   **Deduplication:** Logic is present to prevent the same track/episode URI from appearing multiple times in the final playlist.
